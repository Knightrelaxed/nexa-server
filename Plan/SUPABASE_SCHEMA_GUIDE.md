# 🗄️ PANDUAN DATABASE SUPABASE & SCHEMA SQL
**Sistem Memori N.E.X.A**

Supabase berfungsi sebagai *hippocampus* (memori) bagi N.E.X.A. Tanpanya, N.E.X.A akan memiliki "amnesia" setiap kali Anda mengirim pesan baru, dan sistem pencegahan pencatatan ganda (*Finance Deduplication*) tidak akan berfungsi.

Berikut adalah langkah-langkah absolut untuk mengatur Supabase Anda dengan "Logika Tingkat Tinggi" (*High-Level Schema*).

---

## TAHAP 1: Membuat Project
1. Buka [database.supabase.com](https://supabase.com) dan *Sign In* menggunakan GitHub atau Email Anda.
2. Klik tombol **"New Project"**.
3. Isi *Name* dengan: `NEXA-Core` (atau bebas).
4. Buat *Database Password* yang sangat kuat (simpan *password* ini, meski jarang dipakai).
5. Pilih *Region* terdekat (misal: **Singapore**).
6. Klik **"Create new project"** dan tunggu beberapa menit hingga *database* selesai diputar (*provisioning*).

---

## TAHAP 2: Mengeksekusi Schema SQL N.E.X.A
Ini adalah tahap krusial untuk membuat struktur *database* yang tepat sesuai kode *backend* kita.

1. Di menu sisi kiri *dashboard* Supabase Anda, cari dan klik ikon **"SQL Editor"** (berlogo terminal/kode).
2. Klik tombol **"New Query"**.
3. **Salin (`Copy`) seluruh blok kode SQL di bawah ini, dan tempel (`Paste`) ke dalam editor tersebut:**

```sql
-- ==========================================
-- SCHEMA DATABASE N.E.X.A
-- ==========================================

-- 1. Table untuk Memori Kontekstual (Agar AI bisa mengingat chat sebelumnya)
CREATE TABLE nexa_chat_memories (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  role TEXT NOT NULL, -- Berisi 'user' (Anda) atau 'nexa'
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Table untuk Sistem Deduplikasi Keuangan (Mencegah Pencatatan Ganda dari Tasker/Telegram)
CREATE TABLE nexa_finance_dedup (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  composite_key TEXT NOT NULL, -- Format rahasia: "Nominal_Merchant"
  transaction_time TIMESTAMP WITH TIME ZONE NOT NULL,
  source TEXT NOT NULL, -- Jalur masuk: 'TELEGRAM_MANUAL' atau 'TASKER_LIVIN'
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Membuat Indexing (Logika Tingkat Tinggi untuk mempercepat pencarian data jutaan baris)
CREATE INDEX idx_finance_dedup_time ON nexa_finance_dedup(transaction_time);
CREATE INDEX idx_finance_dedup_key ON nexa_finance_dedup(composite_key);

-- 3. Table untuk Gudang Ide Mentah (Backup dari Google Docs)
CREATE TABLE nexa_2nd_brain (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  content TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

4. Setelah ditempel, tekan tombol **"Run"** (atau `Ctrl+Enter` / `Cmd+Enter`).
5. Jika berhasil, akan muncul tulisan *"Success, no rows returned"*.
   *(Struktur otak Supabase Anda kini telah resmi terbentuk!)*

---

## TAHAP 3: Mengambil Kunci API untuk `.env`
Sekarang kita perlu menyambungkan Supabase ini ke *server* N.E.X.A Anda.

1. Di menu sisi kiri, klik ikon **"Project Settings"** (berlogo gerigi/roda gigi) di paling bawah.
2. Di sub-menu, pilih **"API"**.
3. Di bagian **Project URL**, salin URL-nya dan masukkan ke file `.env` sebagai:
   * `SUPABASE_URL=https://xxxxxxxxx.supabase.co`
4. Di bagian **Project API keys**, cari kunci yang memiliki label **`anon`** dan **`public`**. Salin kunci panjang tersebut dan masukkan ke file `.env` sebagai:
   * `SUPABASE_KEY=eyJhbGciOiJIUzI1NiIsIn...`

---
*Setelah 3 langkah ini selesai, N.E.X.A Anda kini memiliki ingatan permanen dan kebal dari bug pencatatan keuangan ganda!*
